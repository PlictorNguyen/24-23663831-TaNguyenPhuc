# E-commerce Storefront

A multi-page front-end storefront built as a university web development project. The repository organizes the interface into separate pages and shared CSS, JavaScript, and image assets.

## What’s included

- Store home page and product catalogue
- Product detail pages
- Shopping cart and checkout screens
- Login and registration screens
- About, contact, and news pages
- Sitemap

## Built with

- HTML
- CSS
- JavaScript

## Project structure

- `html/` — page templates, including the home page at `html/index.html`
- `css/` — stylesheets
- `jss/` — JavaScript files
- `img/` — image assets

## Run locally

Open `html/index.html` in a browser. This is a front-end course project; checkout and account pages are interface demonstrations and do not process real orders or accounts.

# Website bán hàng

Đồ án giao diện web bán hàng nhiều trang, xây dựng bằng HTML, CSS và JavaScript. Dự án gồm trang chủ, danh mục và chi tiết sản phẩm, giỏ hàng, thanh toán, đăng nhập, đăng ký, giới thiệu, liên hệ, tin tức và sơ đồ trang.

Mở `html/index.html` bằng trình duyệt để xem giao diện.
